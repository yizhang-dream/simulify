# Archived Simulify v1 Workbenches

This folder preserves earlier Simulify v1 workbenches moved out of the active v2 showcase gallery while keeping their git history and standalone runnable files intact.

## Archived Entries

- [`prob-stat-ch5-bench/`](prob-stat-ch5-bench/index.html) — Probability & Statistics Ch.5 5-act instrument bench (L² conditional expectation projection, discrete counts with FPC, square transforms & tower law, Poisson–Gamma / Pareto tails, and χ² / t / F sampling domes). Archived from the v2 flagship showcase (`examples/index.html`) and thumbnail manifest; relative imports remain wired so it can still be opened from a local static server started at the repository root.
