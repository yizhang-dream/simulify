# Simulify (plugin entry shim)

The full skill lives at the repository root. This thin shim exists so plugin loaders that only scan `skills/<name>/SKILL.md` (Antigravity, Claude Code) can discover it.

**When invoked: read [../../SKILL.md](../../SKILL.md) completely and follow it.** Every relative path in that file (`kit/`, `primitives/`, `shell/`, `scripts/`, `references/`, `examples/`, `tests/`) resolves against the **repository root** (two levels above this file), not this directory.
