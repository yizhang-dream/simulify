# Simulify v3.1 Step 0 · Grounding Brief

先确定读者卡在哪个结构、变量或因果关系，再决定什么必须能转动、剖开、回拖或调参。

## 按输入取证

| 输入 | 做法 |
|---|---|
| 短提示词 | 静默核查机理真源并起草 Grounding Brief。最多问一个能改变认知切入点的问题。 |
| 论文、讲义、源码或截图 | 从材料提取基准失效、空间或因果拓扑、1–2 个主导方程及参数、故障工况或消融四件套。 |
| 要求已明确 | 核对关键定量依据，直接带着摘要进入设计确认。 |

## 核对四项核心信息

1. **定量依据**。优先查定律原式、论文、手册或标准的字段、单位、工作区间和阈值，整理成可输入 `solve(params, t)` 的数据。
2. **典型误区**。从教学资料、例题或实验寻找读者常犯的错，写成可重现的分叉、基准对照与结构化 `falsifyCases`（失效边界校验）。
3. **部件与自由度**。列出主要 BOM、固定和转动／滑动关系、轴线、运动范围以及被遮挡的内部。机械档的这些数据用于下一步建立正交蓝图。
4. **可观察的顿悟点**。挑一个能通过拖拽、剖开或回放验证的现象。可参考成熟的领域教程，仍以本题的真实模型和参数为准。

## 材料如何进入模型

- **论文或技术文档**。找 baseline 为什么失效，机制图中谁连着谁，哪一两项决定结果，以及去掉哪部分会复现失效。把 ablation 变成可调故障工况。
- **讲义**。找单一核心定理、插图画不出的演化或遮挡、可代入的例题，以及最容易做错的概念题。
- **源码**。定位状态更新函数、关键不变量与临界分支。选一小段真实执行路径，用 `LinkBus` 同步代码与 3D 状态。
- **截图或草图**。记录可见部件、坐标和标注，显式列出缺失的背面深度和时间变化。只有高影响未知量需要跟用户确认。

## 确认切入点

短提示词可给 2–3 个具象选项，推荐项放第一。例如开放式差速器可聚焦转弯时左右轮速关系、单轮低附着时两侧扭矩受限，或用可测量的轮速验证角速度约束。不同焦点决定手柄、极限实验和公式取舍。用户要求直接做时，用三行假设卡交代焦点、Profile 和版式、预设故障工况。

## 交付给 Step 1

- 用 `[Verbatim / Measured]`、`[Canonical]`、`[Pedagogical Scale]` 标明关键参数与比例的依据。保留来源，比例夸张写在标尺或图注中，证据缺口写成明确假设。
- 留下核心认知钩子、控制方程与参数、部件和自由度、可测失效边界校验，以及 `mechanical-3d`、`field-math`、`sandbox-direct` 之一和所选布局、皮肤。原生真源和载体见 [fidelity-isomorphism.md](fidelity-isomorphism.md) 与 [topic-fit.md](topic-fit.md)。
